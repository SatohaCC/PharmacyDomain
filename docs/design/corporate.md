# 法人の境界

Corporateは店舗・スタッフ・患者のデータを隔離するテナント単位です。
法人の上に企業グループを表す集約は置かず、各法人を対等に分離します。

## 組織と本人を分ける理由

本人・アカウントは法人の外に存在し、法人アクセス権が所属法人と利用範囲を結びます。
転籍・複数法人兼務のために本人を複製したり、Corporateへユーザーやロールを埋め込んだりしません。
代表者とシステムの初期管理者も別の役割です。店舗やスタッフの詳細は各コンテキストが所有します。

## 法人の停止とテナント認可

法人停止は配下の通常業務を止める入口であり、店舗状態・個別アカウント停止とは独立です。
他コンテキストは法人のApplication実装へ直接依存せず、利用側のBoundaryを通じて存在と有効性を確認します。
他法人と未存在は同じNotFound系の応答に畳み、存在や件数を開示しません。

権限・店舗範囲・保存前再検証は[Application設計](application.md#認証認可とテナント境界)、
法人と初期管理者の登録手順は[認証運用](../local-authentication.md)を参照します。
契約プラン・課金は業務モデルの対象範囲とは別に扱います。
