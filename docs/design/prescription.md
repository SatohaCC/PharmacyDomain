# 処方原本と疑義照会

Prescriptionは受領した処方箋原本、Rpごとの指示、疑義照会と回答、調剤開始可否・終端状態を所有します。
実際の調剤結果はDispensing、指導記録はMedicationHistory、資格台帳・適用固定値はCoverageの責務です。

## 状態と原本の完全性

未回答の疑義照会の有無は照会履歴から導出し、独立した状態として二重管理しません。
処方削除の回答は原本の無効化に当たるため、記録と同時に取消済へ畳みます。
調剤済・取消済の場合は終端を維持して回答記録を残します。

疑義照会結果が電子処方箋の調剤編に送信されても、照会対象は処方原本なので履歴の所有者はPrescriptionです。
医師分割の指示は処方原本、薬局判断の分割理由は各調剤セッションへ分けます。
引換番号の一意性は受領元ごとの判断とし、一律の全体一意性を要求しません。

## 外部規格の解釈

| 根拠 | 適用範囲 |
| --- | --- |
| JAHIS 院外処方箋2次元シンボル記録条件規約 Ver.1.11 | 紙処方箋の記録と使用可能なコード |
| 電子処方箋管理サービス 記録条件仕様 処方編Ver.2.4 | 電子処方箋原本と別表 |
| 同 調剤編Ver.2.2 | 疑義照会結果など送信時の写像 |
| 保険調剤の理解のために 令和8年度 | 使用期間・リフィル・分割・減数調剤 |

レコード番号や別表番号が似ていても、受領元ごとの使用可能コードを混ぜません。
薬品レコードは処方編・調剤編とも「薬品コード X 13 可変」とされるため、一律の固定桁数を不変条件にしません。
原典が桁数を指定する保険者番号等とは区別し、コード種別の妥当性は対応マスタ側で扱います。
処方原本の特殊公費も、資格台帳での第一〜第四公費へ機械的に写しません。

リフィル指示は交付日時点の医薬品規制区分で判断し、未収載・判定不能ならfail-closedで拒否します。
別表16の薬品補足と変更制限は独立した列挙とし、到達不能な組合せを重複検証しません。
用量はDecimalで表し、不均等服用の合計をfloat誤差で拒否しません。
