# PharmacyDomain

> **薬局・調剤ドメインの複雑なビジネスルールを、DDDとオニオンアーキテクチャとPythonで厳格かつエレガントに表現する試み**

---

## 📌 プロジェクトの目的とビジョン

**PharmacyDomain** は、医療・調剤薬局領域の複雑な業務ドメイン（マルチテナント法人、店舗、保険薬局指定番号、資格情報、配属・兼務履歴管理など）のルール・不変条件を、データベースや Web フレームワークから独立した**純粋なドメインモデル**としてモデル化・実装す試みです。

最中心のドメインモデルから外側へ向けて依存性を一方向に限定する **オニオンアーキテクチャ（Onion Architecture）** に準拠し、ドメインモデル貧血症（Anemic Domain Model）の防止、型安全、集約の境界保護、値オブジェクトの自己検証を徹底しています。
