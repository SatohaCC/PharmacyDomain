# 範囲付きユーザー権限のレビュー修正

確認日: 2026-10-29

## 修正内容

PR #81の二件の指摘を修正した。

法人管理者の店舗利用停止は、操作者の店舗一覧から対象を除くだけでは不十分だった。
既存の認可とRepositoryの取得範囲が法人管理者を例外扱いし、停止した店舗の業務記録を読み書きできた。
法人・店舗・スタッフの管理と店舗での業務を分け、店舗業務の認可とSQL取得条件の両方に有効な店舗利用範囲を適用した。
停止した店舗の処方箋の取得・更新を404にし、他店舗の処方箋参照と法人内の店舗管理は維持することを実DB・本番配線のHTTPテストで確認した。

登録画面でスタッフ新規作成を選んでから法人管理者へ切り替えると、非表示になった作成モードが残り、選んだ既存スタッフとは別のスタッフを作ろうとしていた。
法人管理者の任意スタッフ指定は、画面に表示される既存スタッフの選択として処理するよう修正した。
ロール切替を実際に行い、選んだスタッフに本人を対応させ、そのIDを登録要求へ渡すE2Eを追加した。
