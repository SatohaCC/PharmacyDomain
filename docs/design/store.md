# 店舗と管理薬剤師

Storeは店舗の同一性、開局時間、営業状態、管理薬剤師の任命を所有します。
スタッフの資格・雇用・所属履歴はStaffが所有し、患者・処方・調剤の詳細を店舗へ保持しません。

## 状態と業務の開始・継続

有効・休止・閉局を区別し、新規業務は有効な店舗だけ、継続業務は閉局していない店舗で行います。
業務を開始できるかと既存記録を完成できるかを分け、休止だけを理由に記録を凍結させません。

閉局は通常の状態変更では元へ戻せません。誤操作の訂正としてベンダー専用の閉局取消を設け、
休止へ戻します。閉局時に打ち切った管理薬剤師の任命を復元せず、任命なしの店舗が即座に新規業務を受け付ける状態を避けます。

## 開局時間

全7曜日の週次予定と特例日で表し、定休日も明示します。祝日は自動推定せず特例日として登録します。
時間帯は終了を含まない半開区間とし、終端の00:00だけを24時と解釈します。
開局判定はOPEN・CLOSED・UNKNOWNで答え、予定未登録を「開いている」に倒しません。
店舗が有効でなければ、予定に関わらず閉局中として判定します。

## 配置義務と専任義務

薬機法第7条の配置と専任は、店舗の営業状態とは別の条件です。
新規業務は業務日の管理薬剤師在任を要求し、継続業務は不在を理由に既存記録を止めません。

専任義務はスタッフ番号ではなく自然人にかかるため、法人をまたいでも同じ本人の任命期間が重ならないようにします。
スタッフと本人の取り違えはリンクへの複合外部キーでも防ぎ、アプリケーションの確認だけに依存しません。
任命と所属・利用権限の整合は、[Applicationの認可と保存前Guard](application.md)で更新時にも確認します。

法令の名称は[一次資料](../references/README.md#法令)、期間制約の実装方針は[永続化とDI](infrastructure.md)を参照します。
