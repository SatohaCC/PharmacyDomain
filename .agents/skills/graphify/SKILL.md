# graphify

## 調査

1. カレントディレクトリの `graphify-out/graph.json` を確認し、存在すれば再利用する。なければ `rg` と対象ソースで調べ、構築は明示的な構築依頼がある場合に行う。
2. `graphify query "<識別子・検索語>" --budget 1500` を実行する。経路には `--dfs`、既知の2点には `graphify path`、特定概念には `graphify explain` を使う。
3. グラフで候補を絞り、結論に関わる現在の型・振る舞いは対象ソースで確認する。出典は `source_location` を使い、推論と抽出を区別する。
4. 空の結果・語彙不一致・CLI利用不可の場合だけ[検索の詳細](references/query.md)の該当節を読む。十分な結果が得られれば終了する。

## 読み込みと出力量

- このリポジトリではこのSkillを入口とし、同名のユーザー共通Skillを追加で読まない。
- 参照先は実行する操作に必要な節だけ読む。グラフJSON・語彙一覧・レポートは対象を絞って読む。
- 検索予算は原則1500。不足する関係が明確な場合だけ対象を絞って再検索する。これは検索出力の目安であり、会話全体のトークン上限ではない。
- 調査だけなら結果保存や更新を行わない。コード変更後は差分更新を使う。
- 費用記録の0や記録なしを削減実績と扱わない。実測値がなければ削減率は未検証と伝える。
