# 1回の調剤と鑑査

Dispensingは自局で行った1回ごとの調剤、変更調剤、担当者と最終鑑査を所有します。
レセコンから届く受付NSIPS単位で完結させ、複数回の分割・リフィル追跡を同じ集約へ持ち込みません。

## 自局実施分と回次

他薬局で実施した回は自局の集約にならないため、自局セッションの件数から処方箋全体の調剤回数を導出しません。
各セッションが回次を持ち、同じ処方箋・回次の重複を防ぎます。
医師分割、長期保存困難等による分割、後発品試用の分割とリフィルを同じ回数規則へまとめません。

原本との整合性は利用側の不変な参照情報を介して判断し、薬剤師資格等の外部確認はApplication Boundaryへ委ねます。
中止状態と理由を一致させ、調剤終了は単なる総回数到達ではなく調剤結果の終了区分を根拠に処方箋へ反映します。

## 変更調剤と鑑査

| 軸 | 記録する事実 |
| --- | --- |
| 代替調剤 | 銘柄・後発品等への置換。変更前後が同一の記録は拒否 |
| 数量調整 | 減数など数量を変えた理由 |
| 調製方法 | 一包化・粉砕などの処理 |

電子処方箋の調剤結果には実際に調剤した薬品を記録し、原本との差分と本モデルの変更理由を分けます。
調剤者と鑑査者はIDで保持します。鑑査者の薬剤師資格は確認しますが、一人薬剤師体制を表せるよう別人であることは要求しません。

調製の事実と、それが加算対象になるかは別の判断です。算定・加算の排他・点数や、
機器への包装・容器の指示を調剤集約へ混ぜず、診療報酬改定から業務記録を切り離します。
調剤保存と処方箋への結果反映の原子性は[Applicationの保存境界](application.md#保存前guardとトランザクション)で扱います。

## 外部根拠と未解決事項

薬剤師法第19条・第23条・第25条の2・第26条を担当者、調剤、情報提供と記録の根拠に使います。
「保険調剤の理解のために」令和8年度の§3-1通則は、2回目以降の次回調剤予定日と前後7日以内の原則、
減数調剤が用法・用量を変えず投与日数等を減らすことを定める資料として扱います。
電子処方箋管理サービス 記録条件仕様の調剤編Ver.2.2は送信形式の根拠です。

リフィルと分割の併用可否の原典確認、複数回セッション間の追跡、他薬局で実施した回の把握は未解決です。
資料の所在は[一次資料](../references/README.md)、経緯は[設計判断](../decisions.md)を参照します。
